# Life Playbook

A personal operating system: principles, frameworks, and protocols for living well, written as plain Markdown. No build tools, no app. Read it on GitHub or in any Markdown viewer.

It is opinionated and practical. Each file covers one subject: what it is, the principles that matter, and protocols or checklists you can use.

---

## Where to Start

1. **[index.md](index.md)** — the full table of contents, grouped by section.
2. **[principles.md](principles.md)** — the core values and decision filter everything else serves.
3. **[the-architecture.md](the-architecture.md)** — how the files fit together, in five layers from foundation to synthesis.
4. **[the-unit.md](the-unit.md)** — the synthesis: the complete-individual doctrine the playbook builds toward.

Then pick the area that matters most to you right now and read its file. Don't try to read everything.

## How to Use It

Reading changes little. Practice does. A sensible starting set, each linked to its file:

- **Daily:** the morning and evening anchors in [routines/daily.md](routines/daily.md); a deep-work block ([career/work-principles.md](career/work-principles.md)).
- **Weekly:** the reset in [routines/weekly-review.md](routines/weekly-review.md).
- **For big decisions:** log them with a probability in a [decision journal](decision-journal.md).
- **Body:** sleep ([health/sleep.md](health/sleep.md)) and training ([health/fitness.md](health/fitness.md)) before anything else.
- **Money:** the wealth sequence in [career/finances.md](career/finances.md).
- **Security baseline:** one hour with [opsec-and-privacy.md](opsec-and-privacy.md).
- **Yearly:** [routines/annual-review.md](routines/annual-review.md).

Add one practice at a time. Keep the ones that work.

## A Note on Accuracy

The playbook cites research, history, and quotations. It has been through two search-based fact-check passes, and claims that are contested, unverified, or opinion are marked as such in the text. Health, mental-health, legal, and financial content is general education, not personal advice. Check what matters with a qualified professional, and see [scientific-thinking.md](scientific-thinking.md) for how to judge claims yourself.
