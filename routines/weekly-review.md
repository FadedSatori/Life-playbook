# Weekly Review

Run this every Sunday or Monday morning. Takes 20–30 minutes. Keeps you from drifting.

---

## 1. Clear the decks

- [ ] Inbox to zero (email, messages, notes)
- [ ] Capture any open loops still in your head
- [ ] Review and update any active project lists

## 2. Review the past week

Answer these questions briefly (no more than 2–3 sentences each):

- What were my top 3 accomplishments this week?
- What didn't get done, and why?
- Where did I waste time or energy?
- What was the highlight — the moment I felt most alive or engaged?
- What drained me?

## 3. Assess the key areas

Rate each from 1–10 and note one thing to improve:

| Area | Score | One thing to improve |
|------|-------|----------------------|
| Health | | |
| Work / Career | | |
| Relationships | | |
| Learning | | |
| Finances | | |
| Mental state | | |

## 4. Plan the coming week

- What are the 3 most important outcomes for this week?
- What deep work blocks need to be scheduled?
- What commitments or relationships need attention?
- Is there anything on my plate that shouldn't be there?

## 5. Close

- [ ] Calendar reviewed and next week blocked appropriately
- [ ] Tomorrow's priorities set
